# 地牢探险 Roguelike 游戏

使用 Python + Pygame 开发的经典 Roguelike 地牢探险游戏。

## 功能特性

- **随机地图生成**：每层都有随机房间和走廊，50×50的网格地图
- **职业系统**：战士、法师、盗贼三个职业
- **装备系统**：武器、盔甲、头盔、靴子、饰品五种类型，品质从白色到金色
- **战斗系统**：回合制战斗，伤害数字显示
- **怪物系统**：普通怪、精英怪、BOSS，AI系统
- **道具系统**：药水、卷轴等道具
- **商店系统**：可以购买和出售装备
- **存档系统**：自动存档，死亡后删除存档，本地排行榜

## 安装运行

### 安装依赖
```bash
pip install pygame
```

### 运行游戏
```bash
python main.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格 | 攻击 |
| I | 打开背包 |
| E | 装备物品 |
| U | 使用物品 |
| TAB | 商店切换买卖模式 |
| 回车 | 确认/交易 |
| ESC | 暂停/返回 |

## 游戏目标

- 探索5层地牢
- 击败每层都有更强的怪物
- 找到并击败第5层的终极BOSS"远古巨龙"
- 收集装备、升级角色
- 尽可能达到更高的分数和层数

## 房间类型

- **普通房间**：有怪物和道具
- **宝箱房间**：有宝箱可以开启
- **商店**：可以买卖装备和道具
- **休息点**：可以恢复生命和魔力
- **陷阱房间**：小心陷阱
- **BOSS房间**：每层最后的强大敌人

